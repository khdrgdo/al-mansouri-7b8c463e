# ذاكرة المناصير — خطة البناء الكاملة

منصة أرشيف رقمي عربية (RTL) لتاريخ وتراث ومناطق وشخصيات المناصير: موقع عام + لوحة تحكم إدارية + قاعدة بيانات + تخزين ملفات + خريطة تفاعلية + بحث شامل.

## الهوية البصرية
- ألوان: أخضر النيل العميق، رملي ترابي، عاجي، فحمي داكن، ذهبي هادئ. لا بنفسجي، لا نيون، لا تدرجات مبالغ فيها.
- خط عربي: IBM Plex Sans Arabic. الاتجاه RTL بالكامل، تصميم متجاوب مصمم للجوال أولًا.
- إحساس: متحف رقمي / موسوعة تاريخية، لا شبكة اجتماعية ولا لوحة SaaS.

## Backend (Lovable Cloud)
جداول: `admins/user_roles`, `articles`, `historical_events`, `locations`, `people`, `archive_items`, `documents`, `comments`, `advertisements`, `submissions`, `categories`, `tags`, `sources` + جداول ربط (مقال↔موقع، مقال↔شخصية، مقال↔حدث، أرشيف↔موقع، أرشيف↔شخصية، وسوم).
- حقول عامة لكل محتوى: حالة النشر (مسودة/منشور)، حالة التوثيق (موثّق/رواية شفهية/غير مؤكد)، المصادر، تاريخ الإنشاء.
- الأمان: الزائر يقرأ المنشور فقط، ويكتب في `comments` / `submissions` / `advertisements` بحالة «قيد المراجعة». كل الكتابة والتحرير الإداري محمي بدور `admin` عبر جدول أدوار منفصل ودالة تحقق آمنة.
- التخزين: مجلد صور عام + مجلد وثائق مقيّد، مع تحقق من نوع وحجم الملف.
- حماية من السبام: حد معدل الإرسال، فحص طول المحتوى، حقل فخ مخفي.

## الموقع العام (صفحات مستقلة لكل قسم)
- الرئيسية: هيرو سينمائي + مقدمة + إحصائيات حية من قاعدة البيانات (مناطق/مقالات/صور/وثائق/شخصيات) + مختارات.
- التاريخ: خط زمني تفاعلي + صفحة لكل حدث (وصف، صور، وثائق، مصادر، مواقع وشخصيات مرتبطة).
- المناطق: دليل مناطق/قرى/مواضع/معالم مع بحث وفلاتر + صفحة تفصيلية لكل موقع.
- الخريطة: خريطة OpenStreetMap تفاعلية، العلامات من قاعدة البيانات (لا بيانات مضمّنة في الواجهة)، بحث وتصفية وفتح تفاصيل الموقع.
- الأرشيف: معرض بتصنيفات (صور قديمة، المناطق، النيل، التراث، المناسبات، الشخصيات، الوثائق، الخرائط) + عارض صور Lightbox + معاينة/تحميل الوثائق.
- الشخصيات: دليل + صفحة لكل شخصية مع المصادر وتمييز غير المؤكد.
- المقالات: قائمة + بحث + تصنيفات + وسوم + مقالات ذات صلة + أزرار مشاركة + صفحة لكل مقال.
- الإعلانات: دليل إعلانات بتصنيفات + نموذج «أعلن في دليل المناصير» (يدخل قيد المراجعة).
- ساهم في التوثيق: نموذج رفع صور/وثائق/روايات/تصحيحات دون تسجيل.
- التعليقات: اسم + تعليق على المقالات/الأحداث/المواقع/الشخصيات، لا تظهر إلا بعد الموافقة، مع زر إبلاغ.
- بحث شامل عبر كل أنواع المحتوى مع فلاتر.
- صفحات: سياسة الخصوصية، شروط الاستخدام، تواصل معنا.
- تذييل كامل بالروابط المطلوبة + رابط «إدارة الموقع».

## لوحة الإدارة `/admin`
- تسجيل دخول آمن بالبريد وكلمة المرور، محمي بالكامل، مع تسجيل خروج وإعادة تعيين كلمة المرور.
- حساب المدير: `khdrmamon@gmail.com` (يُنشأ ويُمنح دور admin ضمن الإعداد؛ كلمة المرور تُحدَّد عند أول دخول عبر إعادة التعيين).
- إحصائيات: مقالات، مواقع، شخصيات، عناصر أرشيف، تعليقات معلقة، مساهمات معلقة، إعلانات نشطة، إعلانات منتهية، نشاط حديث.
- أقسام: المقالات، التاريخ، المناطق، الخريطة، الشخصيات، الأرشيف، الوثائق، التعليقات، الإعلانات، مساهمات الزوار، إعدادات الموقع.
- لكل نوع محتوى: إنشاء/تعديل/حذف/نشر/مسودة/بحث/فلترة/رفع صور/حقول المصادر، مع نوافذ تأكيد للحذف، وموافقة/رفض/إيقاف/جدولة للإعلانات والتعليقات والمساهمات.

## SEO والأداء
- عنوان ووصف وOpen Graph لكل صفحة، عناوين دلالية، روابط نظيفة، خريطة موقع، robots.
- ترقيم صفحات، تحميل كسول للصور، حالات تحميل/فراغ/خطأ، استعلامات محدودة (لا تحميل الأرشيف كاملًا).

## سياسة المحتوى
لا اختلاق لأي معلومة تاريخية. المحتوى التجريبي المبدئي يكون قليلًا وواضح أنه نموذج قابل للاستبدال، وكل سجل يحمل حقل مصدر وحالة توثيق.

## ترتيب التنفيذ
1. تفعيل Lovable Cloud + المخطط الكامل والصلاحيات والتخزين.
2. نظام التصميم RTL + الهيكل العام (رأس، تذييل، تنقل) + الرئيسية.
3. الصفحات العامة: التاريخ، المناطق، الشخصيات، المقالات، الأرشيف، الخريطة، البحث.
4. النماذج العامة: التعليقات، المساهمات، الإعلانات.
5. تسجيل دخول الإدارة + لوحة التحكم وكل أقسام الإدارة والمراجعة.
6. SEO، خريطة الموقع، الأداء، الصفحات القانونية، والمراجعة النهائية.
