# ذاكرة المناصير الرقمية

اقرأ ملف المواصفات المرفق بالكامل واجعله المرجع الأساسي للمشروع.



ابنِ الموقع كاملًا وليس UI فقط: Frontend + Backend + Database + Admin Dashboard + Authentication للإدارة + Storage + Map + Search + Articles + History + Locations + Archive + People + Comments + Advertisements + Visitor Contributions + Moderation + SEO.



الزوار يتصفحون ويعلقون ويرسلون مساهماتهم بدون تسجيل، بينما الإدارة فقط تحتاج إلى حساب Admin.



نفّذ كل ما ورد في الملف، ولا تحذف أو تختصر أي قسم منه. اجعل الموقع عربيًا RTL، Responsive، Premium، سريعًا، وآمنًا، وبهوية «ذاكرة المناصير». لا تخترع معلومات تاريخية؛ اجعل المحتوى التجريبي قابلًا للاستبدال بالمصادر الموثقة.
